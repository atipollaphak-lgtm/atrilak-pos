# ระบบ POS ร้านอตรีลักษณ์ คอนกรีต (Version 1.0)

## ข้อมูลร้าน

* ชื่อร้าน: อตรีลักษณ์ คอนกรีต
* จำนวนสาขา: 1 สาขา
* ใช้งานเครื่องเดียว
* เครื่องพิมพ์ A4
* ขายเงินสด
* ไม่มีระบบเครดิต
* รองรับ VAT แบบรวมในราคา
* สามารถเปิด/ปิด VAT ได้จากหน้าตั้งค่า
* มี QR PromptPay สำหรับรับชำระเงิน
